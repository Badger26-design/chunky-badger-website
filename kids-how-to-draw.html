Our Simple Method

How Kids Can Learn to Draw in 6 Simple Steps

Chunky Badger's unique approach to helping kids learn how to draw removes the barriers that usually discourage young artists. No rules. No frustration. Just six simple shapes that build into something brilliant.

1

Start with a Basic Shape

Every drawing starts with a simple circle, oval, or blob. This first shape forms the body — and it's so easy that any child can do it.

2–4

Build Up the Features

One step at a time, features are added — legs, ears, tail, eyes. Each step is shown as a picture so kids can see exactly what to draw without any confusing instructions.

5–6

Add Detail & Colour

The final steps add all the personality: fur texture, face details, and a full practice box to colour and customise. The result is a drawing children are genuinely proud of.
